# Hidemi MIST — App Data Outline
## 1. Overview
- **Full Name:** Hidemi MIST
- **Tagline:** Send & Receive USDC Privately Across Blockchains
- **Description:** A private on-chain payment app that lets users send and receive USDC across multiple blockchains without leaving a transaction history. Powered by zero-knowledge proofs for cryptographic privacy.
- **Website:** MIST.cash
## 2. App Metadata
- **Category:** Finance
- **Price:** Free
- **Age Rating:** 4+
- **Version:** 0.1.0
- **Platform:** Web (PWA — Progressive Web App)
## 3. Core Value Proposition
- Restores financial privacy for on-chain USDC payments
- No transaction history exposed
- No wallet address revealed when receiving payments
- No tracking cookies or behavioral analytics
- Privacy is cryptographic (mathematically proven), not just obfuscated
## 4. Key Features
### 4.1 Create a Payment Link
- Generate a secure payment link and share it with anyone
- Recipients can pay without the sender's wallet address being exposed
### 4.2 Receive from Any Chain
- Accept USDC from any of the six supported blockchains
- Cross-chain compatibility with no additional setup required
### 4.3 Complete Privacy
- Withdraw, offramp, or transfer USDC with zero transaction history exposed
- Withdrawals are not linkable to deposits
### 4.4 Zero-Knowledge Proofs
- Transactions are verified without revealing sender or receiver details
- Payment links use cryptographic secrets to keep wallet activity private
- Not just obscurity — mathematically proven confidentiality
### 4.5 Passkey Authentication (WebAuthn)
- No passwords or seed phrases required for login
- Biometric authentication (fingerprint/face) via WebAuthn standard
- Biometric data never leaves the user's device
- A backup seed phrase is generated only as a fallback recovery option
### 4.6 Mobile-First Design
- Built and optimized for mobile phones
- Fast and responsive interface
- Works anywhere as a PWA

## 6. How It Works
1. **Create a Payment Link** — Generate a secure link; no wallet address is exposed to the payer
2. **Receive from Any Chain** — Sender pays with USDC from any of the six supported blockchains
3. **Withdraw Privately** — Withdraw, offramp, or transfer USDC with zero transaction history, powered by ZK proofs
## 7. Privacy Model
- Every standard on-chain payment is publicly visible by default (salary, purchases, transfers)
- Hidemi MIST breaks this by using ZK proofs so:
  - Sender details are not revealed
  - Receiver wallet address is not exposed
  - Deposits and withdrawals are unlinkable
  - No tracking cookies or behavioral analytics are used
## 8. Security Model
- **Non-Custodial:** MIST never holds user funds; all transactions go through on-chain smart contracts
- **Open Protocol:** Built on proven cryptographic primitives with auditable smart contracts
- **No Passwords:** Nothing to hack or phish; authentication is passkey/biometric only
- **No Seed Phrase Required:** WebAuthn passkeys replace seed phrases; seed phrase exists only as optional backup
## 9. Onboarding & Access
- No sign-up required
- No email required
- Connect with a passkey to start receiving private USDC payments immediately
## 10. Pricing
- **Free to use**
- Users only pay standard blockchain gas fees for on-chain transactions
